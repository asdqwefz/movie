Frequently asked questions

What is MoviesParty?

MoviesParty is a watch party service for watching movies together online. You create a room, send the room code to your friends and everyone presses play at the same time, with voice, video and text chat beside the player.

Is MoviesParty free?

Yes. The free plan includes 1080p, public rooms and chat. Premium adds 4K Ultra HD, private rooms and priority sync, and its pricing has not been announced yet.

Does MoviesParty host the movies?

No. Each person plays their own copy or their own subscription, and MoviesParty only syncs the playhead so everyone sees the same frame at the same second.

How do my friends join a room?

Share the room code with them. They install the Windows app, open it and enter the code to walk right in. macOS is on the way.
